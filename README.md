# Python Practice Collection

A collection of introductory Python scripts for conditions, loops, operators, and unit conversions.

## ✨ Highlights

- Odd/even checks and marks in `New project/Blessings.py`.
- Weight conversion and a validation loop in `New project/Extra.py`.
- Additional exercises cover operators, condo pricing, and mileage.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "New project/Blessings.py"
```

Follow the prompts in the terminal.
